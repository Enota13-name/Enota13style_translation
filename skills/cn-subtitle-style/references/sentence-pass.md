# 语义划句与全局对齐

识别器提供词和时间，语言模型负责句子结构，最终时间由全局词序与波形共同确定。不要把已有 ASR 分段当成真正句子。

## 一、语义划句

通读全文后判断真实边界：

- 主谓结构和语义完整才算一句；
- 相邻识别片段合起来才完整时必须合并；
- Yeah.、No.、All right. 等短应答可以独立；
- 不按固定字符数、静音阈值或 ASR 片段机械切句。

标点阶段默认只加标点，不加词、不删词、不改词、不调序。每个完整英文句子保留句内标点并补句末标点。确需修正误识别词时，把修改列入 correction report，并让修订文本重新参与对齐。

## 二、逐词验证

审校文本与原始识别文本使用同一规范化规则：

- 小写；
- 去除纯标点；
- 连字符、数字和缩写拆成字母数字子词；
- 保留原始词序。

若只补了标点，规范化后的完整词序必须一致。不一致就先解决文本差异，不能让对齐脚本猜。

## 三、全局单调对齐

把所有句子的子词串联成一条完整序列，再与 ASR 子词序列一次性对齐：

- 完全相同时按顺序直接映射；
- 少量差异使用全局序列对齐；
- ASR 索引必须严格递增，同一个词只能归属一次；
- 每个句子的首尾索引来自全局映射，不再独立搜索；
- 替换、缺词、多词合并和不连续跨度必须报告。

只有未解决的局部区域才允许在“预期位置附近”使用首尾词组救援，并逐步加长词组。不得回到全篇盲搜，也不得让一个失败句子把后面所有游标带偏。

## 四、长句拆分

优先合法切点：

- 完整句末；
- and、but、or、so、as、with、because、when、while、if、that、which、who 等从句或并列结构起点；
- 分词、介词短语起点；
- 逗号之后。

尺度来自人工成品：

| 项目 | 目标 |
|---|---:|
| 英文单条目标 | 约 47 字符 |
| 常规硬上限 | 约 85–90 字符 |
| 常规时长上限 | 约 8 秒 |

多个合法切点都能满足显示宽度时，评分同时考虑：

1. 语法边界强度；
2. 与目标宽度的距离；
3. 相邻词之间的停顿长度。

优先选自然停顿明显的从句边界。没有合法从句边界但英文必然溢出屏幕时，才退回最后一个可显示的词边界，并在报告中标为 width fallback。不能拆开单词。

中英双语模式下，如果这次拆分仅为容纳英文行，而中文本身完整且放得下，可以让相邻英文条目重复同一中文，不必把中文强行切碎。

## 五、时间轴

全局映射先给出每条首词和末词的粗边界，随后必须执行 [波形与时间轴精修](timing-refinement.md)：

- 句首、句尾都由波形优先；
- 每个视频单独测量 ASR 偏差；
- 连续语音使用本视频校准值或词边界；
- 相邻候选冲突时用局部能量低谷和语义边界解决；
- 量化到 0.01 秒后再次检查重叠。

独立锚点只能做救援，不能作为最终声学边界。

## 六、运行

先用本地识别导出 words.json，再运行：

    python scripts/build_sentences.py \
      --sentences 划句-1.txt 划句-2.txt \
      --words words.json \
      --media 输入视频.mp4 \
      -o 输出.en.draft.ass

脚本负责全局词序定位、从句拆分和英文初稿。波形精修完成前文件名保留 draft，不交付为最终稿。

## 七、交付检查

- 句子总词序与审校文本一致；
- 全局映射无回跳、无重复词索引；
- 未对齐和 width fallback 已列出；
- 普通对白无重叠；
- 波形、视频校准和低置信回退各自有数量；
- 所有时间点最后才量化到 ASS 精度。
