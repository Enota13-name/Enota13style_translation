# 语音识别与初稿数据

transcribe.py 只负责把视频里的语音转成文字和词级时间戳。它不是最终切分者，也不负责波形精修；划句与全局定位见 [语义划句与全局对齐](sentence-pass.md)，最终声学边界见 [波形与时间轴精修](timing-refinement.md)。

## 两种用法

正式流程只识别，不生成字幕：

    python scripts/transcribe.py 视频.mp4 --dump-json 时间戳.json

快速预览可一步生成临时英文 ASS：

    python scripts/transcribe.py 视频.mp4 -o 英文预览.ass --csv

两个输出参数都不给会直接报错。正式流程中，build_sentences.py 根据全文单调对齐写出英文 draft；波形复核、可选中文和最终质检完成后才成为交付稿。

## 参数

| 参数 | 作用 |
|---|---|
| --dump-json | 导出原始片段和逐词时间 |
| --silence-ms | VAD 静音阈值，只影响识别和快速预览 |
| --language | 源语言，默认 en |
| --model | 指定本地识别模型 |
| --csv | 快速预览时同时输出表格 |

## 视频转格式

源文件需要转换时，保留分辨率、帧率、色彩和音频参数；不要仅为识别而重复压制。必须转 mp4 时可用 ffmpeg，并在执行前报告会重新编码视频。

## 识别质量的已知问题

- 背景音乐盖住人声时，Whisper 可能把少量词摊在很长的时间范围。
- 连续独白没有停顿时，VAD 不能提供句子边界。
- 连字符、数字和缩写可能被拆成不同 token。
- 词时间来自模型估计，不等于声学真值，部分素材会整体偏早或偏晚。

这些问题都不能靠固定字符数或历史偏移量解决。语义划句负责文本边界，全局对齐负责词序，波形精修负责真实句首句尾。

## 每个视频单独校准

从前后有明确静音的高置信条目测量：

- 真实起振点减去首词时间；
- 真实衰减终点减去末词时间。

使用中位数和 MAD 排除异常值。只有样本足够且分布稳定时，才把本视频的校准值用于连续语音。旧视频的 +0.38 秒/+0.26 秒不能迁移成新视频默认值。

## 时间轴与阅读速度

- 普通对白不得重叠。
- 阅读速度补偿只能借用真实空档；借不到就报告偏快，不侵占邻近对白。
- 词时间交叉时，不可能同时完整包含两个词且保持不重叠，必须标为冲突并复核波形。
- 不同位置的译者注释属于有意叠加，与普通对白重叠分开统计。
