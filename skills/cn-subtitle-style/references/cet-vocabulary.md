# 四六级词汇标红

把英文字幕里的四六级词汇标成红色，并输出一份出现位置和释义的文档。用来做学习辅助，或者做带生词提示的字幕版本。

## 知识库

| 文件 | 内容 |
|---|---|
| `assets/cet_vocab.json` | 8278 个四六级词，含级别（四级／六级）、音标、中文释义 |
| `assets/common_words.json` | 3564 个常用词，标红时要排除的部分 |

词汇来源是多个公开词库的并集：CET4/CET6 标准词表、星火巧记四级和六级、乱序版四级。释义优先取标准词表的简洁版本，缺失时用星火版的详细释义（带词性）。源数据里的占位释义（如"找不到解释"）已剔除。

## 常用词为什么要单独维护

四六级词表本身就收录大量基础词。不过滤直接标红的话，实测**近半数单词会变红**，包括 is、what、this、your、my 这类词，标红就失去意义了。

所以排除以下四类：

1. 高频词表 top2000
2. 高考 3500 词汇
3. 牛津 3000 常用词
4. 手工整理的基础功能词（代词、介词、连词、助动词、数词）

前三项合计过滤掉 3564 个词，扣除后实际可标红的词汇是 4714 个。同样两个测试视频，命中从 455 次降到 17 次。

**如果觉得太严**：去掉高考词汇那一层，命中会从 11 个词变成 29 个，多出来的是 poison、rabbit、meanwhile、outside、perhaps 这类"确实是四六级词但日常也常用"的词。调整方式是在 `build_cet_kb.py` 的 `COMMON_FILES` 里增删词表后重新生成。

## 运行方式

```bash
python scripts/mark_cet.py \
  --item 英文稿.ass 词级时间戳.json video1 \
  --out-dir ../outputs
```

`--item` 可以重复传多组，一次处理多个视频。三参数依次是：字幕文件、`transcribe.py --dump-json` 产出的词级时间戳、输出的标签名。

### 沿用已有的标红

**不要每次都重新计算。** 重新分段之后，标红要跟着迁移，用 `--marks-from` 指向旧文件即可：

```bash
python scripts/mark_cet.py \
  --item 新英文稿.ass 词级时间戳.json video1 \
  --marks-from 旧的标红版.ass \
  --out-dir ../outputs
```

脚本按这个顺序决定标红清单：

1. 指定了 `--marks-from` → 用那份文件里的标红单词
2. 没指定，但输入的字幕文件本身带标红标记 → 用文件里的
3. 两者都没有 → 才按知识库从头检测

这样用户手工调整过的标红（去掉某个词、手动补一个词）不会被覆盖。加 `--refresh` 可以强制忽略已有标记、重新检测。

标红是幂等的：已经是红色的词不会再加一层标签，所以对同一个文件重复运行是安全的。

产出：

- `<标签>.cet.ass`：命中词标红的字幕，每个词标完立刻还原成白色
- `cet-words-in-videos.md`：出现明细（精确到词的时间戳、级别、释义、所在字幕）加去重词汇表
- `cet-words-in-videos.csv`：同内容的表格版

时间戳取自词级时间戳，不是字幕条的起始时间，所以词在句中靠后时也准。

## 词形处理

字幕里的词是变形，词表里是原形，匹配时按下面的顺序还原：原形 → 不规则变化表 → 后缀规则（复数、过去式、进行时、副词）。**不做 -er/-est 还原**，因为会把 master 判成 mast、matter 判成 matt。

## 更新词库

```bash
python scripts/build_cet_kb.py
```

脚本会从上游拉取各词库并重新合成两个 JSON 文件，需要联网。词库来自 qwerty-learner 项目的公开词表。
