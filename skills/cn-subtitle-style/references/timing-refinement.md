# 波形与时间轴精修

目标不是给所有字幕机械加减若干秒，而是让文本边界、逐词对齐和真实声音边界互相验证。

## 证据优先级

1. 人工确认的参考时间轴；
2. 清晰波形中的真实起振点和衰减终点；
3. 全局单调强制对齐得到的逐词边界；
4. 从同一视频高置信样本测得的 ASR 校准值；
5. 独立首尾词锚点只作局部救援，不再作为主流程。

任何低级证据都不能覆盖更高级证据。

## 一、全局文本对齐

- 将审校文本和 ASR 结果用同一规则规范化：小写、拆分连字符和数字、去除纯标点。
- 把全文作为一条单调序列对齐，记录每个审校词对应的 ASR 词索引。
- 同一个 ASR 词只能使用一次；索引必须严格递增。
- 完全一致时直接顺序映射，不做锚点搜索。
- 少量差异用全局序列对齐处理；替换、缺词和多词合并必须进入报告。
- 只有局部未对齐区可以用加长词组在预期位置附近救援；不得回到全篇盲搜。

这一步解决“上一句末锚点与下一句首锚点相同，导致后续整体错位”的问题。

## 二、语义与停顿共同选切点

合法切点首先必须是：

- 完整句末；
- 从句、并列结构、介词短语或分词短语的起点；
- 逗号后的自然边界；
- 因屏幕宽度不得不退让时的词边界。

多个合法切点同时存在时，综合：

- 语法边界强度；
- 当前英文行宽是否接近用户目标；
- 前后词之间的真实停顿；
- 中文是否能保持自然语义单元。

优先选有自然停顿的从句边界，而不是只选最接近字符目标的位置。

## 三、波形边界

从源视频提取单声道 PCM，计算短窗 RMS 或等价能量包络，并在每条首词、末词附近估计**局部底噪**。这里的“回到零”指回到局部噪声底，不是数字音频的 0 dBFS。

高置信句首：

- 前方存在一段持续安静；
- 包络从局部底噪稳定跃升；
- 起振点与强制对齐词头处在合理邻域。

高置信句尾：

- 末词后包络持续衰减；
- 回到局部底噪并维持安静；
- 没有音乐、混响或下一句语音覆盖。

瞬时音节低谷不能当成静音。检测必须要求持续安静窗口，避免旧测试把连续语音中的短低谷误认成句首。

## 四、每个视频单独校准

Whisper 词时间可能相对真实波形整体偏早或偏晚，偏差会随素材、模型和混音变化。处理每个视频时：

1. 筛选前后都有明确静音的高置信条目；
2. 分别计算“真实起振 − 首词开始”和“真实衰减终点 − 末词结束”；
3. 用中位数和 MAD 去除异常值；
4. 样本数量足够且分布稳定时，得到该视频的句首/句尾校准值；
5. 只把该视频的校准值用于没有清晰波形边界的连续语音。

旧素材测出的句首约 +0.38 秒、句尾约 +0.26 秒只是一条视频的结果，不能成为新视频常量。样本不足时保持词边界并标低置信度，不能硬套历史值。

## 五、相邻字幕的冲突处理

先生成两个候选：

- 上一条的声学终点；
- 下一条的声学起点。

若终点早于起点，保留自然空档。若两者交叉：

1. 在两个词之间搜索局部能量最低点；
2. 检查切点是否仍在合法语义边界；
3. 使用同一个边界结束上一条并开始下一条，保证不重叠；
4. 若波形持续混杂，退回强制对齐词边界并标低置信度。

词时间本身发生交叉时，不可能同时满足“完整包含两个词”和“不重叠”。必须报告冲突并声学复核，不能声称两个条件都已满足。

## 六、中文阶段

- 翻译不改变真实语音边界。
- 中文太长时先压缩译文，再考虑在已有语义切点拆分。
- 英文仅因屏幕宽度拆分而中文无需拆分时，允许重复中文。
- 为阅读速度借时间只能使用真实空档；不能侵占邻近对白。

## 七、量化与质检

所有计算先保留毫秒精度，最后一步才转为 ASS 的 0.01 秒：

- 量化后重新保证 start < end；
- 主对白按时间单调；
- 普通对白重叠为 0；
- 译注重叠单独识别；
- 报告高置信波形边界、视频校准回退、低置信回退和无法解决的词时间冲突数量。

抽听优先级：

1. 低置信和时间冲突；
2. 音乐、混响、多人抢话；
3. 极短条目和长句拆分处；
4. 中文重复或重新分段处；
5. 随机抽查高置信条目，防止算法系统性漂移。
