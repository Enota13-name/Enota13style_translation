# 英文识别、打轴与中文字幕成品

这套流程分三段：DeepSeek 与本地模型产出英文初稿；按用户每次的选择决定是否生成中文；ChatGPT 负责语言、样式和时间轴精修。任何模型都不能跳过声学证据直接凭文字猜时间。

## 每次开始前

1. 先只读检查视频、已有字幕和参考 ASS，报告方案并等待用户授权后再生成或修改文件。
2. **每个字幕任务都必须询问：`本次是否需要生成中文字幕？`** 即使任务看起来只要求英文，也要确认一次。
3. 若需要中文，再确认最终交付是中文单语还是中英双语；不需要中文则只做英文成品。
4. 有参考 ASS 时优先继承其 PlayRes、样式和位置。没有参考时使用 [ASS 样式档案](references/ass-style.md)。

## 三阶段工作流

### 一、DeepSeek + 本地模型：英文初稿

1. 用 `transcribe.py --dump-json` 调用本地 Whisper large-v3，输出逐词文本、起止时间和源视频尺寸；这一步不写 ASS。
2. 由 DeepSeek 或当前语言模型通读全文，按英语语法补标点和划句。只加标点，不擅自增删改词；确需纠正识别词时单独记录，并重新对齐。
3. 把完整审校文本与逐词识别结果做**全局、单调递增对齐**。不得再让每句话独立全篇搜索首尾锚点；重复短语不能令后续字幕整体错位。
4. 在从句边界拆长句，并在多个合法切点中优先选择有自然停顿的位置。详细规则见 [语义划句与全局对齐](references/sentence-pass.md)。
5. 生成 `<名称>.en.draft.ass`。英文初稿采用英文样式，不冒充最终双语成品。

### 二、ChatGPT：可选中文

只有用户确认需要中文时才进入这一段，并读取 [中文翻译风格](references/chinese-style.md) 与项目术语表。

- 按用户的口语、压缩和术语习惯翻译；学习语气与取舍，不模仿错字、病句或识别错误。
- 对上下文连续的多条字幕整体审校，避免逐条翻译造成指代、时态或逻辑断裂。
- 中文通常保持一个自然语义单元。若英文只是因为屏幕宽度被拆成多条，可以像用户人工成品那样在相邻条目中重复同一中文，不必把中文硬劈开。
- 中英双语排列为中文在上、英文在下，使用 `\N`；中文单语不保留英文行。

### 三、ChatGPT + 本地声学数据：精修与交付

1. 对每条字幕的句首和句尾都做波形复核。清晰语音使用真实起振点和衰减回本地底噪的位置。
2. 每个视频先从前后确有静音的高置信样本测量 ASR 的系统偏差，再把稳健校准值用于连续语音。**历史视频测出的 +0.38 秒/+0.26 秒不是通用常量，禁止写死。**
3. 音乐、混响或下一句混入时，退回强制对齐词边界和局部能量低谷，并把条目标为低置信度；不得伪造“波形精修成功”。
4. 时间计算完成后再量化到 ASS 的 0.01 秒，并重新检查单调性。普通对白不得重叠；不同位置的译者注释可以与正文同时间显示。
5. 检查中文连贯性、用户风格、字体字号、位置、PlayRes、换行、阅读速度和所有低置信度时间点。
6. 运行 `scripts/check_style.py` 后输出最终 `.ass`。详细时序算法见 [波形与时间轴精修](references/timing-refinement.md)。

## 不可破坏的约束

- 不在词组中间切句；因屏幕宽度必须拆英文时，只能在词边界退让，并在报告中注明。
- 每个被识别的词必须归属一条字幕；不因固定尾巴或阅读速度补偿侵占下一条。
- 主对白时间轴不得重叠，开始必须早于结束。
- PlayResX / PlayResY 必须等于源视频分辨率。
- 不自动覆盖用户人工成品；覆盖任何已有文件前先建立 `.bak` 或等价备份。
- 自动稿、人工稿和最终稿要用不同文件名，避免把测试稿误当交付稿。

## 四六级词汇标红

用户需要时才生成独立的 `<原名>.cet.ass`，不覆盖干净稿。已有标红必须沿用，只有完全没有标记时才重新检测。详细规则见 [四六级词汇标红](references/cet-vocabulary.md)。

## 交付前检查

- 英文词序与审校文本一致；所有文本改动有记录。
- 全局对齐无回跳、无重复占用、无未解释的缺词。
- 波形高置信边界、校准回退边界和低置信边界数量已报告。
- 中文单条通常 10–20 个汉字；超过约 26 字优先复查，不为了清零提示而破坏语义。
- 中文正文一般不加句末标点；译注、问号和强调按中文风格规则处理。
- 样式来自参考 ASS 或样式档案；ASS 解析、自检均通过。

## 协作约定

- 只读检查无需额外授权；生成、修改、删除、联网或运行长任务前先给方案并取得用户授权。
- 用户只要求方案时停在方案，不提前动手。
- 不主动制作新旧视觉对照；只报告结果和仍需人工判断的异常。
